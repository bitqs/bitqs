# SWARM · 虫潮（工作标题）

> 一款浏览器直开的 survivor/割草游戏，技术招牌是**同屏数千个会"群体行动"的敌人**。
> 技术栈：**Phaser 3/4 + TypeScript + Vite**（渲染/框架）+ **Rust → WebAssembly**（敌群模拟核心，渐进引入）。

本项目按「**人定方向、AI 实现**」的方法推进，从文档起步：

| 文档 | 讲什么 | 状态 |
|---|---|---|
| [PRD.md](./PRD.md) | 做什么 / 为什么（愿景、玩法、MVP 范围、验收标准） | 草案 v0.1 · 待审 |
| [TRD.md](./TRD.md) | 怎么做（架构、**技术栈决策 + ADR**、里程碑、性能预算） | 草案 v0.1 · 待审 |

**技术栈一句话**：浏览器零安装锁定 JS/TS → Phaser+TS 做渲染与玩法；"同屏 2000+ 敌人群体模拟"是真正的性能热点 → 为 Rust→WASM 预留接口，**先用 TS 跑通，达标线不够再上 Rust**（不教条用 Rust）。
