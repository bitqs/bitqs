## 1. 一句话愿景

> **「一念之间，千军清场」** —— 一款浏览器直开的 survivor/割草游戏，核心爽点是**屏幕上同时存在数千个会"群体行动"的敌人**：它们会包抄、会避让、会像潮水一样涌来，被你的技能成片清空。

差异点：市面 survivor 的敌人多是各自independently 朝玩家直线移动；本作的敌人是**一个被模拟的"群"**——有避让、有挤压、有阵型涌动，视觉与策略上都更"活"。这也是本作的技术招牌（见 TRD 的 Rust 模拟核心）。

## 2. 目标用户 & 平台

| 项 | 内容 |
|---|---|
| 目标用户 | 喜欢 Vampire Survivors 类"割草构筑"的轻度~中度玩家；碎片时间玩 |
| 平台 | **桌面 + 移动浏览器**，零下载直开（横竖屏自适应） |
| 单局时长 | 5–15 分钟一局 |
| 商业模式 | MVP 阶段免费、无内购；后续可加局外成长 / 皮肤 |

## 3. 设计支柱（Design Pillars）

任何功能取舍都回到这三条：

1. **群感（Swarm-feel）** — 敌人必须看起来"是一群"，而不是一堆各走各的点。这是本作的灵魂，不可妥协。
2. **一念清场（Power fantasy）** — 玩家成长曲线要让"从被压制到一键清屏"的爽感周期性出现。
3. **零摩擦（Zero friction）** — 打开即玩，30 秒内进入第一场战斗，不教学、靠直觉。

## 4. 核心循环（Core Loop）

```
移动走位 → 自动攻击清怪 → 捡经验 → 升级三选一（构筑）→ 敌群变强/变多
   ↑                                                            │
   └──────────────── 越滚越强 / 直到阵亡或通关 ←─────────────────┘
```

- **自动攻击**：玩家只控制移动，武器自动开火（survivor 标配）。
- **构筑**：每次升级三选一（新武器 / 强化 / 进化），形成 build 多样性。
- **压力来源**：敌群数量与"群行为强度"随时间上升（潮汐式波次）。

## 5. 功能清单（MoSCoW 优先级）

### Must（MVP 必须）
- M1 玩家角色：八方向移动、受击、血量、死亡。
- M2 **敌群系统**：持续生成、群体移动（涌向玩家 + 互相避让）、接触造成伤害。
- M3 至少 3 种武器（自动开火），各有不同弹道/范围。
- M4 经验 + 升级 + **三选一**构筑面板。
- M5 难度曲线：随时间提升敌群密度与速度（潮汐波次）。
- M6 局内 HUD：血量、等级、计时、击杀数。
- M7 结算：阵亡/通关结算页，可重开。
- M8 横竖屏自适应、触屏摇杆 + 键盘双支持。

### Should（强烈想要）
- S1 1 个 Boss（阶段性出现）。
- S2 武器"进化"（满级武器 + 特定被动 → 进化形态）。
- S3 音效与基础打击感（闪白/顿帧/震屏——可复用 bitqs 的 Juice Lab 经验）。

### Could（锦上添花）
- C1 局外成长（金币 / 永久强化）。
- C2 多角色、多地图主题。
- C3 排行榜。

### Won't（本期明确不做）
- 联机 / 多人。
- 账号系统 / 云存档（本期用 localStorage）。
- 复杂剧情。

## 6. 关键用户故事 + 验收标准（EARS 风格）

> EARS 格式：**WHEN [条件] THE SYSTEM SHALL [可观测行为]**，便于直接转成测试。

- **US-1 群体行动**
  - WHEN 敌人数量 ≥ 50 且彼此距离过近，THE SYSTEM SHALL 让它们互相施加避让力，使其不重叠堆成一个点。
  - WHEN 玩家移动，THE SYSTEM SHALL 让敌群整体朝玩家当前位置涌动并产生可见的"潮汐"包抄感。
- **US-2 性能**
  - WHEN 同屏敌人达到 **2000 个**，THE SYSTEM SHALL 在中端手机浏览器上维持 **≥ 50 FPS**（目标 60）。
- **US-3 构筑**
  - WHEN 玩家升级，THE SYSTEM SHALL 暂停战斗并弹出三个**互不重复**的选项；选择后立即生效并恢复战斗。
- **US-4 自动战斗**
  - WHEN 武器冷却结束且范围内有敌人，THE SYSTEM SHALL 自动选择目标并开火，无需玩家点击。
- **US-5 零摩擦启动**
  - WHEN 玩家打开页面，THE SYSTEM SHALL 在 **3 秒内**可交互，并在 **30 秒内**能进入第一场战斗。
- **US-6 自适应**
  - WHEN 屏幕在横/竖屏间切换，THE SYSTEM SHALL 重新布局 HUD 与摇杆且不中断战斗。

## 7. 成功指标（MVP 验证什么）

| 指标 | 目标 | 为什么 |
|---|---|---|
| 首局完成率 | ≥ 60% 玩家打完第一局 | 验证"零摩擦 + 爽感" |
| 同屏敌人数 | ≥ 2000 @ 50fps（手机） | 验证"群感"的技术地基（核心差异点） |
| 次日重玩（如有局外成长） | 观察留存 | 验证构筑深度 |
| 首屏可交互 | ≤ 3s | 验证"零下载直开" |

## 8. 范围边界（Out of Scope）

本期不做：联机、账号、内购、复杂剧情、关卡编辑器。**敌群模拟的"群感"是唯一的技术冒险，其余一切从简。**（呼应研究结论：新技术只引入一项，把学习成本压到最小。）

## 9. 产品侧风险

| 风险 | 缓解 |
|---|---|
| "群感"做出来不明显，玩家无感 | 先做**可视的 A/B 开关**：关掉避让/阵型，对比"死鱼直线 vs 潮汐"，确保差异肉眼可见后再继续 |
| survivor 同质化严重 | 用"群感"+ 进化构筑做差异；美术风格统一化 |
| 性能不达标拖垮体验 | 性能是 Must（US-2）；TRD 用 TS-first → Rust 热点替换的渐进路线兜底 |
